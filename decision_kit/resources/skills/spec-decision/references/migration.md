# Compatibilidad histórica

Nombres anteriores: interpreter → context, researcher → research, builder → analysis,
executor → execute; analysis/result posteriores a ejecución → report.
Para renombrar archivos usa decision/scripts/migrate_case.py --case <caso>.
Renombrar conserva los JSON originales y no reevalúa. Una ejecución antigua sin
provenance no acredita vigencia frente a las fuentes actuales. No se debe crear
procedencia retroactiva: revisa con analysis para preparar una nueva evaluación.
